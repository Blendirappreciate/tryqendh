## 🛠 Troubleshooting

### Playback stuttering

```powershell
# Enable hardware acceleration
# Preferences > Hardware Acceleration > Enable NVIDIA/AMD/Intel

# Create proxies
# Right-click clip > Create Proxy File

# Lower preview quality
# Preview > Preview Quality = Half resolution
```

### Export taking too long

```powershell
# Enable GPU rendering
# Export > Profile Settings > Hardware Acceleration = On

# Use H.265
# H.265 codec faster encoding on modern GPUs

# Lower bitrate
# Export > Quality = 15 Mbps (YouTube) vs 50 Mbps (default)
```

### Green screen not working

```powershell
# Adjust chroma key
# Effects > Chroma Key > Color Picker = Green color

# Refine edges
# Chroma Key > Denoise = 5, Edge Enhancement = 3

# Lighting critical
# Even lighting on green screen essential—reshoot with better lighting
```
